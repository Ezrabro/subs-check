# Sub-Check - Subscription Detection & Conversion Tool

> **Fixed logic, simplified operations, added features, memory saving, one-click start without configuration**

> **Note:** Features are updated frequently. Please check the latest [configuration file](https://github.com/Ezrabro/subs-check/blob/master/config/config.example.yaml) for the latest features.
> **Note:** If you want to view feature updates, you can refer to [example config commit history](https://github.com/Ezrabro/subs-check/commits/master/config/config.example.yaml) for change notes and more feature/logic updates.

## Features
- Node merging
- Node availability detection
- Node deduplication
- Node speed testing
- Streaming media unlock detection
- Node renaming
- Any format subscription conversion
- 100+ notification channels supported
- Built-in Sub-Store
- Web control panel
- Crontab expression support
- Multi-platform support

## Deployment & Usage

First run will generate the default configuration file in the current directory.
